# ADR-0001

## Title

Arona is the primary assistant.

## Status

Accepted

## Context

Blue Archive presents Arona as the guide and assistant for the player.

BlueArch adopts the same design philosophy by making Arona the primary interface for user assistance.

## Decision

Arona will become the central assistant of BlueArch.

She may appear in:

- CLI
- Welcome
- Notifications
- Help
- Widgets

## Consequences

Future applications should integrate naturally with Arona instead of creating multiple assistant systems.
