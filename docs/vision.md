# BlueArch Vision

## What is BlueArch?

BlueArch is an Arch Linux based operating system inspired by Blue Archive.

The goal is not to recreate the game itself, but to build an operating system that feels like it could naturally exist in the world of Kivotos.

## Core Principles

- Keep the Arch philosophy.
- Focus on aesthetics and user experience.
- Arona is the primary system assistant.
- KDE Plasma is the default desktop environment.
- Developer-friendly by default.
- Modular architecture.
- Open source.

## Long-term Goals

- Custom installer
- Custom boot experience
- Arona Assistant
- BlueArch CLI
- Customized desktop experience
- BlueArch ISO
