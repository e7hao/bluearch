# BlueArch Linux

> If Kivotos had an operating system.

BlueArch Linux is an Arch Linux based distribution inspired by the design philosophy and atmosphere of Blue Archive.

## Vision

BlueArch is not just a Linux theme.

The goal is to create an operating system that feels like it belongs in Kivotos, where Arona assists the user throughout the entire desktop experience.
